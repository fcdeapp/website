# 권리·출처 및 재사용 범위

## 독립 제작 부분

새로 작성한 한국어 본문, 독립 제작 SVG·구조화 도식, 편집 메타데이터는 CC BY 4.0으로 제공합니다. 표시 예: “의학 디지털 교과서, 전자판”. 변경 시 변경 사실을 표시하고 의학 검수 완료를 암시하지 마십시오. https://creativecommons.org/licenses/by/4.0/

새 검증·추출 도구와 TypeScript 선언에는 MIT License를 적용합니다. 기존 v0.1의 권리 표기는 보존된 원본 ZIP의 해당 문서를 따릅니다. 서드파티 저작물에 새로운 라이선스를 부여하는 것은 아닙니다.

## BodyParts3D

원본 모델 자체는 이 ZIP에 중복 수록하지 않았습니다. 파생 인덱스·관계·경계상자에 사용된 원본은 첨부 BodyParts3D Release 4.0입니다. 첨부 README와 공식 라이선스 페이지(2025-02-27 변경)를 대조했습니다. CC BY 4.0. 필수 표시:

BodyParts3D, © The Database Center for Life Science licensed under CC Attribution 4.0 International

https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html

수정 사항: 원본 OBJ 변경 없음. 파일 검사·좌표 bounds·관계 JSON 변환, 일부 한국어 번역과 교육용 장면 추가. 라이선스 페이지의 현재 고지를 확인했으며 과거의 CC BY-SA 2.1 JP라는 타 사이트 설명을 현재 조건으로 대체 적용하지 않았습니다.

공통 의학적 사실을 독립 문장으로 설명한 부분과 원본 표현의 번역·각색을 구분했습니다. 본문과 SVG는 특정 교재 문장을 순서대로 번역한 자료가 아닙니다. 참고문헌 항목이 있다고 해당 자료를 모두 재사용 허가받았거나 모든 본문이 검증되었다는 뜻은 아닙니다.

## 추가 조사 자료와 독립 도표

추가 서지의 접근 상태와 원문 재사용 범위는 `references/references.json`의 각 항목에 기록했다. 무료 열람과 원문·번역문·도판 재배포 권한은 구분하며, 이번에 추가한 자료의 원문과 도판은 수록하지 않았다. 출처의 링크와 사실 대조 기록만 제공한다. `diagram.oxygen-content`와 `diagram.bayes-positive`의 SVG 및 수치는 독립 계산으로 제작한 학습 도표이며 실제 환자 자료가 아니다. 원천 출판물의 그림을 변환하거나 복제하지 않았다.


## 분야별 패키지의 출처

OpenStax, NCI, FDA 및 WHO의 이번 조사 자료는 서지의 개별 항목에 접근 범위와 재사용 상태를 기록했다. 원문·번역문·그림·사진을 패키지에 수록하지 않았으며, 무료 열람을 자산 재배포 허가로 간주하지 않는다. 분야별 references는 같은 서지 항목을 해당 분야로 필터링한 것으로 별도 저작권 허가를 추가하지 않는다.
