# MDEET 기출 학습실

`website/public/mdeet`의 300문항을 사용하는 브라우저 기반 학습 도구입니다. 생물학·화학, 2023–2027학년도, 36단원, 10개 시험 세트를 제공합니다. 기존 사이트 설정이나 데이터 수정 없이 이 디렉터리 안에서 구현했습니다.

## 화면과 기능

| URL | 기능 |
| --- | --- |
| `/mdeet` | 실제 풀이 기록, 오늘의 복습, 과목별 진도, 이어 풀기 |
| `/mdeet/library` | 과목별 목차, 단원별 진도와 정답률 |
| `/mdeet/library/[unitId]` | 해당 단원 문항 탐색 및 학습 시작 |
| `/mdeet/questions` | 필터·정렬·페이지 이동·선택 풀이·본문 검색 |
| `/mdeet/questions/[questionId]` | 원본 배치 보기, 확대, 답안·확신도·메모, 채점 및 풀이 기록 |
| `/mdeet/practice` | 과목·단원·연도·배점·학습 상태·북마크·복습일 조건, 문항 수, 무작위 순서, 제한 시간, 채점 방식 |
| `/mdeet/exams` | 10개 시험 세트, 각 30문항·120점 |
| `/mdeet/exams/[examId]` | 답안·확인 표시·진행 위치 저장, 제한 시간, 종료 후 채점 |
| `/mdeet/review` | 오답·불확실·반복 오답·복습 예정·북마크, 메모 |
| `/mdeet/flashcards` | 직접 만든 암기 카드, 문항 연결, 복습 평가와 일정 |
| `/mdeet/analytics` | 최초·최근 풀이 정답률, 단원별 지표, 시간 및 학습 활동 |
| `/mdeet/calendar` | 월·주 보기, 목표 일정 추가·수정·완료, 학습 활동 |
| `/mdeet/settings` | 글자 크기·확대·채점 설정, JSON 내보내기·검증 후 가져오기, 확인 후 초기화 |

예시 문항: `/mdeet/questions/mdeet-2023-chemistry-30`.
예시 시험: `/mdeet/exams/2023-biology`.

## 구성

- 각 경로의 `page.tsx`: 화면 진입점. 동적 경로는 원본 목록을 이용해 정적 생성합니다.
- `layout.tsx`, `loading.tsx`, `error.tsx`: 공통 학습 화면과 로딩·오류 처리.
- `_components/`: 페이지별 기능, 학습 상태 공급자, 문항 렌더러와 세션 실행기.
- `_lib/`: 데이터 로딩, 저장 형식 검증, 채점, 복습 일정 및 분석 계산.
- `_hooks/useQuestion.ts`: 문항 로딩·오류·재시도.
- `mdeet.module.css`: MDEET 내부에 한정한 스타일과 반응형 배치.
- `_tests/core.test.cjs`: 데이터 연결과 핵심 학습 로직 검사.

## 디자인과 문항 렌더링

[참고 교재 내지](https://kmong.com/portfolio/view/277255)의 얇은 청색 선, 머리말·꼬리말과 여백에서 방향을 잡았습니다. 화면은 차분한 청색, 흰 지면, 목차와 표 중심입니다. 참고 이미지 자체는 복제하거나 포함하지 않았습니다.

문항은 `layout`의 모든 영역을 SVG로 그립니다. 원본 좌표·크기·텍스트 기준선·문자 폭과 이미지 경로를 사용하며, 수식의 위첨자·아래첨자를 임의로 재해석하지 않습니다. 이미지형 선택지는 원본 지면 안에 표시하고 답안은 별도의 1–5번 버튼으로 받습니다. 여러 영역에 걸친 문항도 순서대로 표시합니다.

문항 JSON은 필요할 때 읽고 제한된 캐시에 보관합니다. 다음 지면 영역은 화면 근처에 도달할 때 렌더링합니다. 본문 전체 검색은 사용자가 요청할 때 별도로 색인을 구성합니다. 텍스트 보기는 수식·그림 정보가 손실될 수 있음을 표시합니다.

## 학습 기록

기록은 현재 브라우저의 `localStorage`에 `mdeet:learning:v1` 키로 저장합니다. 서버·계정 간 동기화는 없습니다. 이동하려면 설정 화면에서 JSON으로 내보내고 가져옵니다. 손상된 저장값은 자동 덮어쓰지 않고 경고하며, 저장 실패도 화면에 알립니다.

시험은 절대 종료 시각과 답안·진행 위치를 저장하므로 새로고침 이후에도 같은 종료 시각을 사용합니다. 탭을 닫은 동안에도 제한 시간은 흐르며, 다시 열었을 때 만료 여부를 확인합니다. 채점 시 세션과 문항으로 정해지는 기록 ID를 사용해 중복 제출을 방지합니다.

정답은 제출·채점 이후 화면에 표시합니다. 정적 공개 JSON에는 원래부터 정답이 포함되어 있으므로 보안이 필요한 시험 용도는 아닙니다. 원본에 검수된 해설이 없어 해설을 생성하지 않습니다. 복습 간격과 단원 지표는 학습 보조용 규칙입니다.

## 검증

`website` 디렉터리에서 실행합니다.

```sh
./node_modules/.bin/tsc --noEmit --incremental false
./node_modules/.bin/eslint src/app/mdeet
node --test src/app/mdeet/_tests/core.test.cjs
```

- TypeScript와 MDEET 범위 ESLint 통과.
- 핵심 테스트 11개 통과: 300문항·36단원·10세트, 세트별 120점, 792개 이미지 연결, 1부터 시작하는 선택지와 미응답 채점, 중복 제출, 최초·최근 통계, 복습 일정, 암기 카드 일정, 타이머 직렬화, 가져오기 검증, 단원 지표.
- 별도 임시 복사본에서 프로덕션 빌드 및 MDEET 정적 경로 356개 생성 확인. Next.js가 기존 `tsconfig.json`을 자동 수정하지 않도록 원본 작업 폴더에서는 빌드하지 않았습니다.
- 데스크톱 학습 홈의 배치와 스크롤을 브라우저에서 확인했습니다. 이후 브라우저 자동화 시간 초과로 모든 페이지의 시각 검사 및 모바일 실기기 검사는 완료하지 못했습니다. 자동화 로직 검사를 전체 브라우저 E2E 검사로 간주하지 않습니다.

## 데이터 및 상위 사이트의 제한

- 원본 화학 150문항에 `math-layout-review` 검수 표시가 있습니다. 연결이 끊긴 이미지나 데이터 참조는 검사에서 발견되지 않았지만, 이 표시가 수식의 시각적 정확성을 보장하지는 않습니다. 300문항 전체를 원본 PDF와 수동 대조한 상태는 아닙니다. 예를 들어 `mdeet-2026-chemistry-04`의 수식 배치와 `mdeet-2023-chemistry-30`의 이미지형 선택지는 배포 후에도 원본과 대조할 검수 대상입니다. 원본 데이터는 변경하지 않았습니다.
- 기존 RootLayout의 Abrody 헤더와 백엔드 상태 확인·점검 안내가 그대로 적용됩니다. 따라서 MDEET의 데이터·기록은 로컬에서 처리해도 상위 사이트의 점검 안내가 접근을 가릴 수 있습니다. 이를 제거하려면 허용 범위 밖의 RootLayout 변경이 필요합니다.
- 기존 i18n의 서버 `localStorage` 접근 로그와 정적 내보내기에서 기존 rewrites가 적용되지 않는다는 경고가 빌드에 남습니다. 이번 디렉터리 밖의 코드는 수정하지 않았습니다.
- 요청된 기능 범주는 구현했으며, 남은 항목은 전체 문항의 원본 대조 및 전체 화면·모바일 브라우저 검수입니다.

기존 파일·설정·패키지·공개 데이터는 수정하지 않았고, 커밋·푸시·배포는 수행하지 않았습니다.
