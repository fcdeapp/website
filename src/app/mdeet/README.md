# MDEET — 교과서와 학습 기록

전문 교재의 편집 구조를 웹 학습 환경으로 옮긴 MDEET 전용 화면입니다. 상단 메뉴, 교과서 목차, 읽기 지면, 메모 여백을 구분하고 기존 문제 풀이·학습 기록 기능을 유지합니다.

## 페이지

| 주소 | 내용 |
| --- | --- |
| `/mdeet` | 마지막으로 읽은 절, 오늘의 계획과 복습, 교과서 진도, 지식 학습 현황, 문제 성취도 |
| `/mdeet/textbook` | 주요 과목 서가와 과거 시험·보충 교과서 |
| `/mdeet/textbook/[bookId]` | 실제 데이터 순서를 따르는 교과서 목차 |
| `/mdeet/textbook/chapter/[chapterId]` | 단원 도입부와 학습 절 목록 |
| `/mdeet/textbook/read/[sectionId]` | 전체 본문, 핵심 개념, 비교표, 확인 문제, 관련 지식·기출문제, 참고 자료, 개인 메모 |
| `/mdeet/knowledge` | 전체 지식 검색, 교과서·단원·유형·이해·암기 상태 필터 |
| `/mdeet/knowledge?review=1` | 전체 지식 및 원본 질문·정답형 카드 복습 |
| `/mdeet/questions` | 기출문제 검색·필터·정렬·선택 풀이 |
| `/mdeet/questions/[questionId]` | 원본 배치 문항, 답안·확신도·메모, 채점, 관련 개념 |
| `/mdeet/library`, `/mdeet/library/[unitId]` | 단원별 기출문제와 학습 현황 |

| `/mdeet/exams`, `/mdeet/exams/[examId]` | 원본 시험 세트, 답안·타이머 복구, 종료 후 결과 |
| `/mdeet/review` | 오답·불확실·반복 오답·복습 예정·북마크 |
| `/mdeet/flashcards` | 직접 만든 카드의 작성·수정·복습과 원본 지식 복습 연결 |
| `/mdeet/analytics` | 교과서·지식 진도와 실제 채점 기록 분석 |
| `/mdeet/calendar` | 월·주 계획 및 학습 활동 |
| `/mdeet/settings` | 표시 설정, 전체 학습 기록 내보내기·가져오기, 확인 후 초기화 |

### 대표 화면 주소

- 서가: `/mdeet/textbook`
- 생물학 목차: `/mdeet/textbook/biology`
- 효소 단원 도입: `/mdeet/textbook/chapter/enzyme`
- 효소 반응 본문: `/mdeet/textbook/read/enzyme--kinetics`
- 생물학 비교표: `/mdeet/textbook/read/endocrine--other-hormones`
- 화학 본문: `/mdeet/textbook/read/solution--colligative`
- 생물학 문항: `/mdeet/questions/mdeet-2023-biology-30`
- 이미지형 화학 선택지: `/mdeet/questions/mdeet-2023-chemistry-30`

학습 절 ID의 `/`는 주소에서 `--`로 표현합니다. 기존 `2023-biology` 형태의 시험 주소도 유지합니다.

## 디자인

[노트리랩의 교재 내지 포트폴리오](https://kmong.com/portfolio/view/277255)와 제공된 이미지 5장을 직접 확인했습니다. 참고한 원칙은 얇은 청색 편집선, 큰 단원 번호, 번호와 본문의 정렬, 규칙적인 여백, 본문과 학습 도구의 구분입니다. 로고·이미지·구체적인 그래픽은 복제하거나 에셋에 포함하지 않았습니다.

- 아이콘 중심의 전역 사이드바를 텍스트 상단 메뉴로 교체했습니다.
- 서가는 CSS와 독자적인 SVG 선 패턴으로 구성했습니다.
- 목차는 카드 대신 단원 번호·들여쓰기·구분선으로 구성했습니다.
- 본문은 흰 지면, 러닝 헤더, 16px 본문과 1.85 행간을 사용합니다.
- 본문 옆에 현재 교과서 목차와 개인 메모를 배치합니다. 화면이 좁아지면 본문 아래로 재배치하며 목차를 접을 수 있습니다.
- 홈은 큰 KPI 카드 대신 학습 기록부, 계획 목록, 진행선과 정렬된 숫자를 사용합니다.
- 기존 Pretendard와 시스템 폰트를 사용합니다. 외부 폰트나 패키지는 추가하지 않았습니다.

공통 스타일은 `mdeet.module.css`, 새 편집 구성은 `editorial.module.css`에 한정됩니다. 사용하지 않는 기존 사이드바 스타일과 중복 기본 규칙을 정리했습니다.

## 데이터와 기능 보존

화면의 문항·교과서·단원·지식 수는 원본 인덱스에서 계산합니다. 이번 검증 시점의 데이터는 기출 2,125문항, 시험 58세트, 문제 분류 51단원, 교과서 5권·48단원·107학습 절, 지식 1,693개, 질문형 카드 234개였습니다.

교과서의 **328개 blocks 전체**를 원래 순서대로 렌더링합니다. 현재 데이터의 세 가지 유형인 `paragraph`, `keyFacts`, `table`을 모두 지원합니다. 본문을 핵심 개념만으로 대체하거나 요약하지 않습니다. 수식은 원문 문자열을 그대로 보존하며, 임의의 LaTeX 변환이나 수식 수정은 하지 않습니다. 비교표의 모든 행·열을 유지하고 표 내부에서 가로 스크롤할 수 있게 했습니다.

기출문제의 기존 SVG 렌더러는 좌표·기준선·문자 폭·이미지 연결을 그대로 사용합니다. 원본 영역이 여러 개인 문제도 모두 표시합니다. 정답은 제출·채점 이후, 교과서 확인 문제는 정답 확인을 요청한 뒤 표시합니다.

기존 코드가 확장 데이터 이전 형식을 가정하고 있어 다음 호환 처리가 필요했습니다.

- `exams.json`의 실제 시험 구성과 시험 시간을 사용합니다. 같은 연도·과목을 임의로 합치지 않습니다.
- 확장 문항 ID, 과거 물리학·통계학을 지원합니다.
- `acceptedAnswers`의 복수 정답을 처리합니다.
- 정답 미전사 문항은 답안을 보관하되 **채점 보류**로 표시합니다. 오답 통계와 자동 오답 복습에 넣지 않습니다.
- 배점 미확인 문항에 임의 배점을 부여하지 않습니다. 정답·배점이 불완전한 세션은 완전한 원점수처럼 표시하지 않습니다.

기존 문제 풀이·채점·복습 간격·세션 저장 코드를 재사용했습니다. 새 지식 복습도 기존 `scheduleCard` 간격 규칙을 사용합니다.

## 기록 저장

기존 `localStorage` 키 `mdeet:learning:v1`와 버전 1을 유지합니다. 교과서의 읽은 위치·완료·메모, 지식의 이해·암기, 복습 일정·이력은 선택적 `textbook` 필드에 추가했습니다. 이 필드가 없는 기존 기록도 그대로 읽을 수 있습니다.

문제 풀이 기록·세션·개인 카드·계획·설정을 삭제하거나 초기화하지 않습니다. 설정의 JSON 내보내기·가져오기에 교과서 기록도 포함됩니다. 손상된 저장값은 자동 덮어쓰지 않고 경고합니다. 서버·계정 간 자동 동기화는 없습니다.

## 검증 결과

`website` 디렉터리 기준:

```sh
./node_modules/.bin/tsc --noEmit --incremental false
./node_modules/.bin/eslint src/app/mdeet
node --test src/app/mdeet/_tests/core.test.cjs
```

- TypeScript 검사 통과.
- MDEET 범위 ESLint 통과.
- 핵심 테스트 **14개 통과**: 확장 인덱스와 시험 구성, 이미지·텍스트 참조, 복수 정답·미전사·미확인 배점, 중복 제출, 통계 구분, 복습 간격, 타이머 직렬화, 저장 형식 검증, 교과서의 모든 블록·지식·카드 연결, 기존 기록과 새 기록의 함께 내보내기·가져오기.
- 별도 임시 복사본에서 프로덕션 빌드 성공. MDEET 정적 경로 **2,428개** 생성 및 누락 없음 확인.
- 로컬 미리보기의 `/mdeet/textbook` HTTP 200 응답 확인.
- 작업 전후 Git diff와 파일 해시를 비교해 허용 폴더 밖의 기존 파일이 작업 전과 동일함을 확인.

### 수행하지 못한 시각 검수

브라우저 접근 호스트가 연결되지 않았고, 네이티브 Chrome 접근은 `cgWindowNotFound`, Safari 접근은 `timeoutReached`로 실패했습니다. 따라서 이번 개편 화면의 브라우저 스크린샷 검수는 완료하지 못했습니다.

1440·1280·1024·768·390px를 고려한 반응형 CSS는 구현했지만, 해당 폭에서의 실제 렌더링과 브라우저 E2E 동작을 검수 완료한 것으로 간주하지 않습니다. 배포 전 대표 화면의 정렬·표 스크롤·목차 접기·메모 저장·모바일 메뉴를 실제 브라우저에서 확인해야 합니다. 테스트 통과는 시각적 완성도의 검증을 대신하지 않습니다.

## 원본과 상위 레이아웃의 제한

- 학습 절 107개 모두 원본의 `draft-not-independently-verified` 상태입니다. UI에서도 독립 검수 전임을 표시합니다. 전체 범위를 완전히 수록한 검증 교과서라고 표시하지 않습니다.
- 관련 문제는 원본의 단원·키워드 기반 연결 후보입니다. 직접적인 출제 연관성이 확정된 것으로 표시하지 않습니다.
- 일부 과거 문항에는 미전사 정답·미확인 배점·수식 검수 표시가 있습니다. 원본 데이터를 수정하지 않고 상태를 보존합니다. 모든 문항을 원본 PDF와 수동 대조하지는 않았습니다.
- RootLayout에서 `/mdeet`와 하위 경로의 Abrody 헤더를 제외합니다. MDEET 자체 내비게이션과 기존 서버 점검 안내는 유지합니다.
- 기존 i18n의 서버 `localStorage` 접근 로그와 정적 내보내기의 rewrites 경고가 빌드에 남습니다. 허용 범위 밖의 오류를 이번 작업에서 수정하지 않았습니다.

변경은 `website/src/app/mdeet/` 안으로 한정했습니다. 공개 원본 데이터, RootLayout, 전역 CSS, 패키지·설정, 서버·API를 변경하지 않았으며 commit·push·배포도 하지 않았습니다.
